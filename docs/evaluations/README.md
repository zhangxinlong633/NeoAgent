# docs/evaluations/

本目录存放 Neo Agent 的**阶段性系统评价**（成熟度、适用边界、近端优先项）。各篇为主观工程评审纪要，**不是**产品 SLA，也**不是**日常使用手册。

日常用法见 [`../manual.md`](../manual.md)；目标架构与实现对照见 [`../architecture.md`](../architecture.md)。

## 命名与节奏

| 约定 | 说明 |
|------|------|
| 文件名 | `YYYY-MM-DD.md`（评价落笔日；同日多篇可加后缀，如 `2026-09-12-a.md`） |
| 节奏 | 建议按里程碑或约每月一篇；无重大变化时可跳过 |
| 效力 | 以**最新一篇**为当前判断；旧文保留便于对照演进，不删除 |
| 索引 | 本 README「评价一览」表须在新增当日**同一变更内**更新 |

新建一篇时自检：文首属性表含日期；链接指向 `../` 下权威文档；结论写清「已交付 vs 愿景」。
