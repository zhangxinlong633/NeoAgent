# rules/

存放注入 system prompt 的 **Rules** Markdown：身份与答法手册等硬约束。由配置 `rules.paths` 加载（在 bootstrap 之后）。

| 文件 | 说明 |
|------|------|
| `identity.md` | 自称与能力边界 |
| `response-playbook.md` | 总结 / 笔记 / 待办等答法 |

本目录无子目录。权威说明见 [`docs/claw.md`](../docs/claw.md)；使用样例见 [`docs/examples.md`](../docs/examples.md)。Skills 子系统已废弃；可发现能力见 Capability Matrix（`capabilities/`）与 DAG（`dags/`）。
